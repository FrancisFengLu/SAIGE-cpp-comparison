1. 宏观计算流程

Step1 是独立程序，跑一次估计 GLMM 的 β̂/τ̂/μ̂ 和 variance ratio r̂。Step2 把这些 constants 一次性加载进 SAIGEClass，然后对千万级 markers / 万级 regions 做循环。红框 = step2 的主循环（这是我们要并行的部分）。

2. 数据形状 & 维度流（单个 marker 走一遍）

N = 样本数，p = 协变量数，k = 该 marker 的非零 carrier 数。绝大多数计算只触及 k 个样本（不是 N），这是 SAIGE 高速的关键。蓝色 = 一次性加载的 constants，绿色 = 每个 marker 都跑的便宜部分，黄/红/橙 = 慢路径（只在 mask 触发时跑）。每个箭头/节点都标了 shape 和 cost。

3. Region test 组合视图

Region 里有 m 个 variants。每个 variant 先跑一遍单变体管线得到 G̃ᵢ 和 P2ᵢ（= W·G̃ᵢ 或 Σ⁻¹·G̃ᵢ），按列堆成 P1/P2 矩阵。VarMat = P1·P2 给出跨变体的 score 协方差 Σ_S，这是 BURDEN / SKAT / SKAT-O 三个 combinator 的共同输入。三个 test 提取 Σ_S 的不同 feature。
