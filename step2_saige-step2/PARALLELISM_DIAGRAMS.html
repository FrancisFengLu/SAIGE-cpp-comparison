5. Single-variant loop — current serial vs proposed parallel layout

Left: today's loop processes one marker at a time, every marker going through every stage. Right: two-stage proposal — a matrix-level first pass produces candidate flags; only the few markers needing SPA/Firth/ER get fanned out to a thread pool for the existing scalar recompute. Results are merged back in original marker order.
